# Бай-Тандыр — демо во ВКонтакте

Демо-страницы для показа клиентам:

- `index.html` — мини-приложение ВК (меню, корзина, оформление заказа);
- `bot-sandbox.html` — интерактивная песочница VK-бота (нажимайте кнопки, бот отвечает);
- `admin-mockup.html` — как выглядит отдельный бот-админка, куда стекаются заказы
  из мини-приложения, с сайта и из ВК-бота;
- `order-widget.js` — виджет «Заказать» для подключения на сайт (сайт-меню).

Страницы приватные по распространению: не индексируются поисковиками, ссылка передаётся лично.
Исходный код проекта — в закрытом репозитории.
